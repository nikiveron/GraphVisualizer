# 🔘 Визулизатор графов

**Статус:** Готово к использованию  
**Назначение:** Пользовательский интерфейс для наглядной визуализации графов 
**Тематика:** Инструмент для теории графов

---

## 🧩 Описание проекта

Это приложение представляет собой пользовательский интерфейс (UI) для наглядной визуализации графов. Цель проекта — создание инструмента для практикующихся в теории графов, визуализация алгоритмов на графе.

---

## 🔍 Основной функционал

- **Выбор параметров**  
  Есть возможность выбрать является ли граф ориентированным или нет, взыешенным или нет.

- **Визуал**
  - **Вершины** Добавление вершин, их перемещение по полю, удаление.
  - **Ребра и дуги** Добавление связей между вершинами, удаление при удалении вершин и независимое отдельное удаление.

- **Визуализированные алгоритмы**
  - BFS - обход графа в ширину из заданной вершины
  - DFS - обход графа в глубину из заданной вершины
